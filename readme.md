# Assignment 1: Problem Solving with TypeScript & OOP

## Overview

This repository contains my solutions for **Assignment 1**, focused on Problem Solving with TypeScript and Object-Oriented Programming (OOP).

The assignment covers fundamental and intermediate TypeScript concepts, including basic types, functions, optional parameters, readonly tuples, interfaces, type narrowing, generics, Promises, and OOP concepts.

It also includes two blog posts discussing important TypeScript topics.
